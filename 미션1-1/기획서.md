🎬 영화 티어리스트 웹페이지 기획서
1. 누가 쓰나
나 혼자 쓰는 개인용 웹페이지
사용 환경: PC 브라우저
2. 무엇을 하려고
좋아하는 영화 10편을 나만의 기준으로 티어(등급)별로 분류
각 영화에 대한 개인 코멘트 기록
분류 결과와 코멘트를 브라우저에 저장해 다음에 열어도 유지
3. 화면과 동작
티어 구조: 5단계, 별 갯수로 표시
⭐⭐⭐⭐⭐ (별 5개)
⭐⭐⭐⭐ (별 4개)
⭐⭐⭐ (별 3개)
⭐⭐ (별 2개)
⭐ (별 1개)
대기 구역: 처음 열면 10편이 모두 대기 구역에 모여 있음
분류 방식: 영화 카드를 드래그 앤 드롭으로 티어에 넣기
카드 표시: 포스터 없이 제목 텍스트만
코멘트: 영화 클릭 시 팝업 창이 떠서 작성/수정
이동 규칙:
한 영화는 한 곳에만 (중복 불가)
티어 안에서 순서는 상관없음
티어 간 이동만 가능 (대기 구역으로 되돌리기는 없음)
리셋 기능: 없음
4. 필요한 자료
영화 10편의 제목 목록:
쇼생크 탈출
스파이더맨: 뉴 유니버스
트루먼 쇼
기생충
시카고
소원
인턴
파묘
토이 스토리 5
타짜
별도 이미지 파일 불필요 (텍스트만 사용)
5. 완성 기준
✅ 10편 영화가 대기 구역에 뜬다
✅ 드래그로 별 1~5개 티어에 넣을 수 있다
✅ 영화 클릭 시 코멘트를 쓰고 저장할 수 있다
✅ 새로고침해도 분류/코멘트가 유지된다
